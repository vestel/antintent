# AntIntent LifeCycle

This repository contains a skeleton to start AI-enchanced Software Development LifeCycle

The approach is heavy inspired by [The AI-native SDLC playbook](https://claude.com/resources/articles/the-ai-native-sdlc-playbook), but more generalized for my personal means. 

To start working, git clone the repository, copy folder contents in you working folder. 

Un-comment 3 lines in .gitignore file and add to yours, than run your favourite AI-assistant and start populating the intent.
